# 写给吴桦凤的生日礼物

生日：9 月 19 日。线下补办生日会：2026 年 10 月 1 日。

一个无需安装依赖、可离线打开、为手机和电脑适配的生日网站。

## 内容与互动

- 15 张真实照片、3 段完整视频，保留原文件名作为回忆标题。
- 朱拓恺的完整来信和陈思杰的完整祝福，点击两个信封阅读；保留原文措辞和落款。
- 高晋苏、黎奥扬、陈冠宇等朋友的祝福弹幕；来信摘录明确标注，补充祝福不署朋友名字。
- 可以暂停的弹幕、手动播放的生日旋律、点按吹蜡烛、烟花与礼花、可重新点燃的蜡烛。
- 1200 × 1600 PNG 电子贺卡下载。
- 照片放大、视频原声播放、照片/视频筛选、左右切换、触摸滑动切图和键盘操作。
- 尊重减少动态效果设置；视频只在打开后加载，播放视频时停止生日旋律。

访客输入的弹幕仅用于当前页面，不会上传，也不会跨设备保存。

## 本地使用

直接双击 `site/index.html`，不需要 Node.js、Python 或网络。不要只复制 HTML：同一目录下的脚本、样式和 `assets` 都要保留。建议线下生日会提前保存整份目录，避免现场网络影响视频。

## GitHub Pages

仓库：`ZTK1119/wuhuafeng-birthday`。

发布分支：`codex/birthday-site`。`.github/workflows/pages.yml` 将 `site/` 发布到网站根目录。推送修改会自动更新；也可以在 Actions 中手动运行 **Deploy birthday website**。

网页和仓库采用公开访问。`noindex` 仅建议搜索引擎不收录，不是密码保护。站点没有分析追踪、外部字体或第三方脚本；个人令牌不在源代码中。

## 修改内容

- `site/content.js`：媒体标题/顺序、朋友原文、弹幕。内容使用 `textContent` 安全显示。
- `site/index.html`：开场文案和各区块。
- `site/styles.css`：样式与手机适配。
- `site/app.js`：画廊、信封、弹幕、蜡烛、音效和贺卡导出。
- `site/assets/`：全部照片、视频、缩略图和蛋糕。

图片已转为 WebP 并移除 EXIF 元数据。3 个 MP4 保留原始内容与音频，H.264/AAC，约 8 分 29 秒，单个文件小于 50 MiB。照片和信件归原作者所有，没有附加开源授权。

## 蛋糕素材

蛋糕图像使用内置图像生成工具制作一次。最终文件：`site/assets/cake.png`。提示词：法式复古奶油生日蛋糕，白色裱花、深樱桃红樱桃与缎带、银托盘，正面略俯视；顶部中央一根未点燃红白条纹蜡烛；完整主体、透明背景，无文字、数字或人物。火焰由网页叠加，可互动熄灭。

## 已验证

电脑浏览器实际检查了全部图片加载、三个视频的画面/时长/播放、两封信逐段原文一致、弹幕输入与暂停、音乐开关、蜡烛与重新点燃、PNG 导出、键盘关闭弹窗、减少动态效果；320、390、768、1024、1440 像素视口均无页面横向溢出。首次打开不会请求三个完整视频。
